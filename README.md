# Habita

Front-end do sistema imobiliário Habita, focado na AC 1: login JWT e gestão de corretores.

## Stack

- React + TypeScript
- Vite + pnpm
- GraphQL
- Material UI

## Como rodar

1. Copie `.env.example` para `.env` se necessário.
2. Instale as dependências com `pnpm install`.
3. Suba o app:

```bash
pnpm start:dev
```

Acesse `http://localhost:5173`.

## Telas

- `/login` — autenticação
- `/` — dashboard
- `/corretores` — cadastro e listagem de corretores
